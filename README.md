# هدية من القلب

موقع هدية عربي بتصميم عاجي وذهبي، مبني باستخدام React وVite وJavaScript وCSS. يحتوي على استقبال بلوحة أرقام وثلاث هدايا: رسالة، مشغل موسيقى محلي، ومفاجأة تقود إلى موقع خارجي بعد تأكيد صريح. لا قاعدة بيانات أو حسابات أو مفاتيح API أو تحليلات أو خطوط خارجية.

## التشغيل المحلي

ثبّت Node.js (الإصدار 22.12 أو أحدث، أو 24)، ثم افتح Terminal داخل مجلد `golden-gift` واكتب:

```powershell
npm.cmd install
npm.cmd run dev
```

افتح العنوان المحلي الذي يعرضه Vite في الطرفية (عادة `http://localhost:5173`). استخدام `npm.cmd` يتجنب مشكلة منع سكربتات PowerShell؛ يمكن استخدام `npm` في الطرفيات الأخرى. لإيقاف الخادم اضغط `Ctrl+C` في الطرفية، وأكد الإيقاف إذا طلبت الطرفية ذلك.

## تعديل الهدية من ملف واحد

جميع البيانات الشخصية موجودة في **`src/settings.js`**. عدّل النص بين علامتي الاقتباس واحفظ الملف. لا تغيّر أسماء الحقول.

| الإعداد | وظيفته |
| --- | --- |
| `recipientName` | اسم المستلم |
| `senderName` | اسم المرسل أسفل الرسالة |
| `secretCode` | الرمز السري، افتراضيًا تاريخ الميلاد بصيغة DDMMYY كما هو مكتوب في الإعدادات؛ استخدم أرقامًا إنجليزية بين اقتباسين للحفاظ على الأصفار في البداية |
| `receptionTitle` | عنوان الاستقبال |
| `welcomeText` | النص الترحيبي |
| `letterTitle` | عنوان الرسالة |
| `letterContent` | الرسالة العربية؛ استخدم `\n` لسطر جديد و`\n\n` لفقرة جديدة، أو نصًا بين علامتي backtick متعدد الأسطر |
| `closingPhrase` | عبارة الختام |
| `songName` | اسم الأغنية |
| `artistName` | اسم الفنان، ويمكن تركه فارغًا |
| `musicPath` | مسار ملف الصوت المحلي، فارغ افتراضيًا |
| `externalGiftUrl` | رابط المفاجأة، فارغ افتراضيًا |
| `giftCards` | عنوان ووصف كل بطاقة عبر `title` و`description` داخل `letter` و`music` و`external` |

إذا احتوى نصك على اقتباس مفرد فاستخدم اقتباسين مزدوجين حول القيمة أو اهرب الاقتباس بـ `\'`. لا تكرر بياناتك في ملفات المكونات.

## إضافة الأغنية

1. انسخ ملفًا تملك حق استخدامه إلى `public/music`، مثل `our-song.mp3`.
2. اكتب `musicPath: '/music/our-song.mp3'` في الإعدادات؛ لا تكتب `public` في الرابط. يُفضل اسم ملف بسيط دون مسافات.
3. عدّل `songName` و`artistName`.
4. افتح بطاقة «أغنيتنا» واضغط تشغيل. لن يبدأ الصوت تلقائيًا. يدعم الزر الإيقاف المؤقت والاستئناف، ويتوقف الصوت عند مغادرة شاشة الموسيقى. بدون ملف تظهر رسالة واضحة، والمسار الخاطئ يعرض رسالة خطأ وإعادة محاولة.

## إضافة رابط المفاجأة

ألصق رابط وجهتك الكامل داخل `externalGiftUrl: ''` في `src/settings.js`. يجب أن يبدأ بـ `https://` وأن يكون صالحًا، دون اسم مستخدم أو كلمة مرور داخل الرابط. لم يتم إعداد أي وجهة افتراضية.

فتح علبة «مفاجأة لك» يعرض «جاهز تكتشف المفاجأة؟» ووصف «باقي لك شيء واحد أعددته لك». لا يحدث الانتقال إلا عند ضغط «افتح مفاجأتك». يستخدم الموقع `location.assign` للانتقال في نفس علامة التبويب، ويمكن العودة بزر المتصفح. إذا كان الرابط فارغًا تظهر «المفاجأة لم تجهز بعد». الرابط غير الصالح أو غير HTTPS يعرض رسالة دون الانتقال. التحقق يفحص بنية الرابط والبروتوكول، ولا يضمن توفر الموقع الخارجي أو سلوك تحويلاته.

## اختبار الهدايا الثلاث

1. أدخل رمزًا خاطئًا بلوحة الأرقام وتحقق من رسالة الرفض؛ جرّب الحذف والمسح. أدخل الرمز الموجود في الإعدادات واضغط «افتح الحكاية». يمكن إدخال الأرقام بلوحة مفاتيح الجهاز أيضًا.
2. افتح «رسالتي لك» وتحقق من الفقرات والختام والاسم، ثم زر العودة.
3. اختبر «أغنيتنا» بدون ملف، ثم مع ملف فعلي كما سبق، ثم مع مسار غير موجود. تحقق من التشغيل والإيقاف المؤقت وعدم استمرار الصوت بعد الرجوع.
4. افتح «مفاجأة لك» مع إعداد فارغ واضغط الزر للتحقق من الرسالة. جرّب نصًا غير صالح أو رابط HTTP وتأكد من رفضه. ألصق وجهة HTTPS تختارها بنفسك، وتحقق من عدم مغادرة الموقع بمجرد فتح العلبة، ثم اضغط الزر وتحقق من الانتقال والعودة بزر المتصفح. أعد القيمة فارغة إذا لم تكن الوجهة النهائية جاهزة.
5. جرّب أزرار الرجوع، عرض الهاتف والكمبيوتر، واتجاه النص العربي. فعّل تقليل الحركة في نظامك للتأكد من توقف الحركات.

اختبارات المنطق الآلية والبناء:

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run preview
```

الاختبارات الآلية تغطي مطابقة الرمز والتحقق من الروابط. الاختبار الفعلي للصوت يحتاج ملفك، واختبار الوجهة النهائية يحتاج رابطك. أمر `preview` يعرض نسخة الإنتاج محليًا، ويُوقف كذلك بـ `Ctrl+C`.

## تنظيم الملفات

- `src/settings.js`: جميع قيم التخصيص.
- `src/main.jsx`: مكونات الاستقبال ولوحة الأرقام والهدايا والرسالة والموسيقى والمفاجأة والتنقل.
- `src/logic.js`: التحقق من الرمز والرابط.
- `src/styles.css`: التصميم المتجاوب والحركات وتقليلها.
- `public/music`: الملفات الصوتية المحلية؛ اترك `.gitkeep` أو تجاهله.
- `tests/logic.test.js`: اختبارات المنطق.

## الخصوصية والنشر لاحقًا

هذه هدية شخصية وليست نظام حماية حقيقيًا. الرمز والرسالة والإعدادات موجودة في كود المتصفح ويمكن قراءتها وتجاوز الرمز تقنيًا؛ لا تستخدم الموقع لحماية معلومات حساسة. لا يوجد تتبع أو إرسال للبيانات الشخصية في الكود. فتح الرابط الخارجي ينقلك إلى موقع آخر له سياساته الخاصة. لا تُرفع أي ملفات تلقائيًا، ولا يتطلب التشغيل حساب GitHub أو خدمة مدفوعة.

لم يُنشر المشروع. إذا أردت النشر لاحقًا، شغّل `npm.cmd run build` وارفع **محتويات** `dist` إلى استضافة ملفات ثابتة تختارها. يتضمن البناء ما تضعه داخل `public` ورسالتك وإعداداتك؛ راجعها أولًا. المسارات الحالية مناسبة للنشر في جذر النطاق؛ للنشر تحت مجلد فرعي اضبط `base` في إعدادات Vite وحدّث مسار الموسيقى تبعًا له. تواصل مع مزود الاستضافة لمعرفة خطواته؛ GitHub ليس مطلوبًا.

## دخول عيد الميلاد

## النشر على GitHub Pages

تم تجهيز `vite.config.js` ليحدد مسار الموقع تلقائيًا من اسم المستودع أثناء GitHub Actions، مع بقاء التشغيل المحلي من `/`. يعمل مسار الموسيقى المحلي تحت مجلد المستودع أيضًا؛ استمر بكتابة `/music/اسم-الملف.mp3` في الإعدادات.

أنشئ مستودعًا على GitHub باسم تختاره (مثل `golden-gift`) واجعله Public إذا كنت تستخدم GitHub Free. رفع الملفات إلى مستودع عام يكشف كود الرسالة والرمز؛ راجع المحتوى قبل الرفع. ارفع ملفات المصدر و`package-lock.json` ومجلد `.github`، دون `node_modules` أو `dist` أو ملفات البيئة. من Settings ثم Pages اختر GitHub Actions في Source. ملف `.github/workflows/deploy.yml` يبني ويختبر وينشر عند الرفع إلى فرع `main`، ويمكن تشغيله يدويًا من Actions. سيظهر الرابط الفعلي بعد نجاح النشر؛ لم يتم إنشاء مستودع أو رفع الملفات تلقائيًا.

إذا عدّلت الملفات، ارفع التعديلات إلى المستودع نفسه وسيحدّث الموقع على الرابط نفسه. تعليمات GitHub Pages هذه تضبط المسار آليًا وتغني عن ضبط `base` يدويًا المذكور في فقرة النشر العام أعلاه.

### تخصيص شاشة الدخول

شاشة الدخول تعرض ست خانات بحسب طول `secretCode`، وهو نص للحفاظ على الصفر الأول. الرمز موجود في `src/settings.js` فقط ولا يُكرر في المكونات. يمكن تعديل العبارة أعلى اللوحة ورسائل النجاح والخطأ عبر `entryPrompt` و`entrySuccess` و`entryError` في الملف نفسه.

يمكن الإدخال بلوحة الأرقام أو لوحة مفاتيح الكمبيوتر، واستخدام Backspace أو Delete لحذف آخر رقم وEscape للمسح وEnter للتأكيد. يدعم حقل الإدخال الأرقام العربية أيضًا. عند النجاح تظهر رسالة عيد الميلاد لمدة 2.6 ثانية قبل الهدايا. إعداد تقليل الحركة يعطل حركات الأرقام والاهتزاز والنجوم، مع إبقاء رسالة النجاح مقروءة.

تم فصل الدخول في `src/components/Keypad.jsx` وتصميمه الإضافي في `src/birthday.css`. لا تتغير شاشات الهدايا. لاختبار الدخول، شغّل البناء ثم الاختبارات؛ اختبار DOM يستخدم النسخة المبنية في `dist` ويغطي الخانات، الأرقام، الحذف والمسح، الرمز الخطأ، الاحتفال ثم الانتقال والهدايا. هذا لا يغني عن الفحص البصري على جهاز حقيقي.
